# 🧪 PhysAudit-AI Lab

Веб-сервис школьного цифрового физического практикума: обработка CSV-телеметрии с датчиков
(Data Harvest, до 1000 Гц), очистка сигнала, расчёт метрик, ИИ-вопросы в формате PISA и
1-страничный PDF «Цифровой паспорт исследования».

**Приложение:** https://physaudit-lab.streamlit.app

## Возможности

| Модуль | Что делает |
|---|---|
| Загрузка | `.csv` с авто-определением разделителя (`,` `;` таб) и десятичной запятой; 1-я колонка — время (с), 2-я — величина (при >2 колонках можно выбрать) |
| Демо-режим | Если файл не загружен — синтетика 1000 Гц с гауссовым шумом: краш-тест, маятник, тележка, звук, нагрев, RC-цепь |
| Очистка | Фильтр Савицкого–Голея или скользящее среднее, окно настраивается в мс |
| Метрики | Пик (F_max, x_max, v_max, T_max…), длительность процесса Δt (для маятника — период T), площадь под кривой методом трапеций (импульс J = ∫F dt, путь s = ∫v dt …) |
| Socratic AI Auditor | OpenAI `gpt-4o-mini`: 1 PISA-вопрос + критический анализ графика + проверка ответа ученика на «галлюцинации». **Без ключа** — офлайн-шаблоны по типу эксперимента и сверка чисел ответа с измеренными метриками |
| PDF | A4, 1 страница: заголовок, дата, ученик, график, 3 метрики в рамке, вывод ИИ, поле оценки и подписи учителя (кириллица — шрифт DejaVu) |

Тип эксперимента определяется по заголовку колонки: `Force (N)` / `Сила (Н)`, `Position (m)`,
`Velocity (m/s)`, `Sound (dB)`, `Temp (C)`, `Voltage (V)`; прочие — «произвольная величина».

## Формат CSV

```csv
Time (s);Force (N)
0,000;0,12
0,001;-0,35
```

## Локальный запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Для ИИ-режима: `cp .streamlit/secrets.toml.example .streamlit/secrets.toml` и вписать ключ.

## Деплой на Streamlit Community Cloud (бесплатно)

1. Создать **публичный** репозиторий на GitHub и загрузить файлы проекта
   (`app.py`, `requirements.txt`, `.gitignore`, `README.md`, `.streamlit/config.toml`).
2. Зайти на https://share.streamlit.io → **Create app** → выбрать репозиторий, ветку `main`, файл `app.py`.
3. В поле **App URL** указать `physaudit-lab` → ссылка `https://physaudit-lab.streamlit.app`.
4. (Необязательно) **Advanced settings → Secrets**: вставить содержимое `secrets.toml.example` с реальным ключом.
5. **Deploy**.
